# Introduksjon til AWS (Amazon Web Services)

Amazon Web Services (AWS) er en av de mest populære og omfattende skyplattformene, som tilbyr over 200 tjenester fra datasentre globalt. AWS brukes av millioner av kunder, inkludert små oppstartsbedrifter, store foretak og offentlige organisasjoner, for å oppnå skalerbarhet, fleksibilitet og kostnadseffektivitet i deres IT-infrastruktur.

## Hvorfor AWS?

- **Skalerbarhet:** AWS gir muligheten til å skalere opp eller ned basert på behov uten store investeringer i fysisk infrastruktur.
- **Sikkerhet:** AWS tilbyr avanserte sikkerhetstiltak som inkluderer kryptering, tilgangskontroll og kontinuerlig overvåking.
- **Global rekkevidde:** AWS har datasentre over hele verden, som gjør det enkelt å betjene kunder globalt.
- **Betal for bruk:** AWS fungerer på en pay-as-you-go-modell, som reduserer unødvendige kostnader.

## Viktige AWS-tjenester

### 1. **Compute**

#### **Amazon EC2 (Elastic Compute Cloud):**

- Virtuelle servere i skyen som lar deg kjøre applikasjoner med fleksibilitet i operativsystem, prosessorer, lagring og nettverk.

#### **AWS Lambda:**

- En serverløs databehandlingstjeneste som lar deg kjøre kode som respons på hendelser uten å administrere servere.

#### **Amazon ECS (Elastic Container Service):**

- En høyt skalerbar containeradministrasjonstjeneste for å kjøre og administrere Docker-containere.

### 2. **Storage**

#### **Amazon S3 (Simple Storage Service):**

- Skalerbar objektlagringstjeneste som kan brukes til sikkerhetskopiering, arkivering og dataanalyse.

#### **Amazon EBS (Elastic Block Store):**

- Blokklagring for bruk med EC2-instansene dine, ideell for applikasjoner som krever høy ytelse.

#### **Amazon Glacier:**

- Lagring for langsiktig arkivering og sikkerhetskopiering til lav kostnad.

### 3. **Database**

#### **Amazon RDS (Relational Database Service):**

- En administrert relasjonsdatabasetjeneste som støtter MySQL, PostgreSQL, Oracle og SQL Server.

#### **Amazon DynamoDB:**

- En nøkkelverdi og dokumentdatabase som leverer millisekundforsinkelser ved enhver skala.

#### **Amazon Aurora:**

- En høyytelses relasjonsdatabase bygget for skyen, kompatibel med MySQL og PostgreSQL.

### 4. **Networking**

#### **Amazon VPC (Virtual Private Cloud):**

- Gir deg full kontroll over det virtuelle nettverksmiljøet ditt, inkludert IP-adresser og subnett.

#### **Amazon CloudFront:**

- Et globalt Content Delivery Network (CDN) for å levere innhold med lav forsinkelse og høy overføringshastighet.

### 5. **Machine Learning**

#### **Amazon SageMaker:**

- En tjeneste for å bygge, trene og distribuere maskinlæringsmodeller i stor skala.

#### **AWS Rekognition:**

- En tjeneste for bilde- og videoanalyse, inkludert ansiktsgjenkjenning og objektdeteksjon.

### 6. **Analytics**

#### **Amazon Redshift:**

- En rask, skalerbar datalagringstjeneste for å kjøre komplekse spørringer mot strukturerte og ustrukturerte data.

#### **Amazon Kinesis:**

- Lar deg samle, behandle og analysere sanntids datastrømmer.

### 7. **Developer Tools**

#### **AWS CodeBuild:**

- En fullt administrert tjeneste for kontinuerlig integrasjon som bygger kildekode, tester og produserer programvarepakker.

#### **AWS CodePipeline:**

- Automatiserer bygg, testing og distribusjon av applikasjoner.

### 8. **Security**

#### **AWS IAM (Identity and Access Management):**

- Administrer tilgang til AWS-tjenester og ressurser sikkert.

#### **AWS Shield:**

- En DDoS-beskyttelsestjeneste for å beskytte applikasjoner mot angrep.

#### **AWS KMS (Key Management Service):**

- Enkel opprettelse og administrasjon av krypteringsnøkler.

### 9. **Application Integration**

#### **Amazon SQS (Simple Queue Service):**

- En fullt administrert køtjeneste som lar deg koble og skalere mikrotjenester, distribuerte systemer og serverløse applikasjoner.

#### **Amazon SNS (Simple Notification Service):**

- En meldingspubliseringstjeneste som brukes til meldingsdistribusjon og mobilvarsler.

---

AWS tilbyr mange flere tjenester som dekker nesten alle områder av moderne IT-infrastruktur. Disse tjenestene gir organisasjoner muligheten til å innovere raskere og med større effektivitet, samtidig som de reduserer kostnader og komplekse administrasjonsoppgaver.
