# AWS S3 (Simple Storage Service)

## Hva er S3?

Amazon Simple Storage Service (S3) er en objektlagringstjeneste som gir skalerbar, sikker og holdbar lagring av data. S3 er designet for lagring og henting av enhver datamengde fra hvor som helst, og er ideell for bruk i et bredt spekter av applikasjoner, inkludert web, mobil, backup, og big data.

---

## Hva brukes S3 til?

1. **Lagring av statiske filer**: Lagre bilder, videoer, dokumenter og andre filer.
2. **Backup og gjenoppretting**: Sikkerhetskopier viktige data med høy holdbarhet.
3. **Dataanalyse**: Bruk S3 som en datakilde for big data-verktøy som AWS Athena eller EMR.
4. **Webhosting**: Host statiske nettsider direkte fra S3.
5. **Disaster recovery**: Opprett kostnadseffektive og geografisk replikerte backup-løsninger.

---

## Nøkkelkomponenter i S3

### 1. **Buckets**

- **Hva:** Hovedlagringsenheten i S3.
- **Bruk:** Opprett en bucket for å lagre objekter. Buckets må ha unike navn globalt.

### 2. **Objects**

- **Hva:** Hvert enkelt dataelement som lagres i en bucket.
- **Bruk:** Inneholder data og metadata (nøkkel-verdi par).

### 3. **Keys**

- **Hva:** En unik identifikator for et objekt i en bucket.
- **Bruk:** Identifiser objekter ved hjelp av nøkkelnavn.

### 4. **Regions**

- **Hva:** Geografiske steder hvor S3-data kan lagres.
- **Bruk:** Velg en region nærmest brukerne dine for lavere latens.

### 5. **Storage Classes**

- **Hva:** Ulike alternativer for datalagring basert på tilgangsmønstre.
- **Bruk:**
  - **S3 Standard:** Hyppig tilgang.
  - **S3 Intelligent-Tiering:** Automatisk optimalisering av lagringskostnader.
  - **S3 Standard-IA:** Sjelden tilgang med lavere kostnad.
  - **S3 Glacier:** Arkivlagring for langsiktig data.
  - **S3 Glacier Deep Archive:** Ekstremt lavkost arkivlagring.

### 6. **Access Control**

- **Hva:** Administrer tilgang til buckets og objekter.
- **Bruk:** Bruk IAM-policyer, bucket-policyer og tilgangskontrollister (ACLs) for å beskytte data.

### 7. **Versioning**

- **Hva:** Hold styr på tidligere versjoner av objekter.
- **Bruk:** Beskytt mot utilsiktet sletting eller overskriving.

### 8. **Lifecycle Policies**

- **Hva:** Regler for automatisk flytting av objekter mellom lagringsklasser eller sletting av objekter.
- **Bruk:** Optimaliser kostnadene ved å arkivere eller slette eldre data automatisk.

### 9. **Encryption**

- **Hva:** Beskytt data under lagring og overføring.
- **Bruk:** Bruk server-side encryption (SSE) eller klient-side encryption.

### 10. **Transfer Acceleration**

- **Hva:** Øker hastigheten for filopplastinger over lange avstander.
- **Bruk:** Reduser forsinkelser for globale brukere.

## Typiske scenarier

- **Webhosting**: Lagre og levere statisk innhold som HTML, CSS og JavaScript.
- **Big Data og analyse**: Lagre store datasett for behandling og analyse.
- **Backup og arkivering**: Sikkerhetskopier sensitive data med redundans.
- **Applikasjonslagring**: Bruk som lagring for mobil- og webapplikasjoner.

---

## Fordeler med S3

- **Skalerbarhet**: Ubegrenset datalagring med automatisk skalering.
- **Høy holdbarhet**: 99,999999999% (11 9-er) holdbarhet på data.
- **Sikkerhet**: Robust tilgangskontroll og krypteringsalternativer.
- **Kostnadseffektivitet**: Velg lagringsklasse basert på behov.
- **Integrasjon**: Sømløst integrert med andre AWS-tjenester som Lambda, CloudFront, og Athena.

---

## Kom i gang med S3

1. **Opprett en bucket:**

   ```bash
   aws s3 mb s3://<bucket-name>
   ```

2. **Last opp en fil:**

   ```bash
   aws s3 cp <file-path> s3://<bucket-name>/
   ```

3. **Hent en fil:**

   ```bash
   aws s3 cp s3://<bucket-name>/<file-name> <destination-path>
   ```

4. **Sett opp en bucket-policy:**
   - Gi eller begrens tilgang til spesifikke brukere eller tjenester.

5. **Aktiver livssyklusregler:**
   - Administrer objekter og flytt dem til rimeligere lagringsklasser automatisk.

---

Ved å bruke S3 kan du lagre og administrere data på en skalerbar, sikker og kostnadseffektiv måte som dekker dine applikasjons- og brukerbehov.
